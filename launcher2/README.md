## Alcances alternativos

1. **Visual (A):** reemplazar la UI, conservar el PowerShell actual. Entrega más rápida, pero limita mejoras estructurales.

3. **Reescritura (C):** rehacer instalación, actualización, networking y publicación de una vez. Libertad arquitectónica máxima a cambio de riesgo alto en compatibilidad y operación.

- Experiencias multimedia accesibles sin sesión Minecraft, lanzamiento autónomo de standalone, reanudación de descargas y verificación antes de ejecutar.
- Bootstrap con actualización transaccional, reintentos y rollback verificable; publicar solo tras pruebas host, cliente, LAN y reinstalación.
- Funciones específicas de acceso remoto del host con el alcance de autorización propio; **no** habilitar SSH en instalaciones de amigos.
